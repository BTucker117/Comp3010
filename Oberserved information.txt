All files show various external GET requests leading back to 192.168.1.96, this is not inherently suspicious. Searching the host name for gerv.gun shows a mail scam where a supposed invoice in a zip file contained a dangerous JavaScript file that triggered a local WinHTTP call. This gerv.gun presumably ran on the host to then download the trow.exe & wp.exe files which injected the PUSHDO Trojan virus that both Snort & Suricata picked up.
